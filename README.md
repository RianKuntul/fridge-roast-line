One line, biggest laugh: a roast of a smart fridge whose ice maker has unionized and gone on strike — complete with demands and a ban on being introduced as "the noisy one in the corner".

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): exactly one line, 1–200 characters, no trailing newline.
